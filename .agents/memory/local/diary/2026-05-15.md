# 2026-05-15

## Deploy-SshKey: фиксы по результатам боевого запуска

- **TrustedHosts**: добавлен `Initialize-LocalWSMan` (`TrustedHosts=*`, Basic, AllowUnencrypted, запуск службы WinRM). Без этого WinRM-fallback падал с "Клиенту WinRM не удается обработать запрос... TrustedHosts...".
- **UAC**: новая функция `Assert-Admin` (в [../topics/architecture.md](../topics/architecture.md)) — пробует поднять окно через `Start-Process -Verb RunAs`, при отказе печатает инструкцию и выходит. Подключена во все три Deploy-*.ps1.
- **YAML inline `#`-комментарий**: парсер `Parse-SimpleYaml` теперь срезает `#` после whitespace. До этого `password: PUT_PASSWORD_HERE  # hint` сравнивалось со строкой `PUT_PASSWORD_HERE` и всегда не совпадало → скрипт молча использовал значение с комментарием как пароль.
- **Пустой YAML-скаляр**: `target_user:` / `private_key_path:` без значения парсер давал как пустой `@{}`; `-not @{}` = `$false`, поэтому ветка дефолта не срабатывала. Стрингификация давала `System.Collections.Hashtable`. Добавлен helper `_AsString`.
- **Get-LocalGroupMember на DC**: на одном из доменных контроллеров падал с "Группа S-1-5-32-544 не найдена". Известный баг командлета. Добавлен фоллбек через `[ADSI]"WinNT://./Administrators,group"` в обоих вариантах скрипта (WinRM-scriptblock и SSH-encoded). Локализованное имя группы — через `Translate(NTAccount)` от SID.
- **Вложенные группы Administrators не детектились** — все user-хосты в логе получали ключ в `~/.ssh/authorized_keys` вместо `administrators_authorized_keys`, потому что `Get-LocalGroupMember` показывает только прямых членов. Доменный админ числится в `BUILTIN\Administrators` через `Domain Admins → BUILTIN\Administrators` — прямой записи нет. Post-check на всех таких хостах валился `Permission denied (publickey)`. Фикс: когда `targetUser` совпадает с текущим залогиненным, идём через access token (`WindowsPrincipal.IsInRole`) — он учитывает всю вложенность. Иначе откатываемся на старый путь.
